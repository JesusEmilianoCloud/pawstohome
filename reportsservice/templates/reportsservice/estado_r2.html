Comandos de Gestión

Utiliza estos comandos desde la terminal para gestionar las imágenes:

Migrar todas las imágenes a R2:
python manage.py migrate_images_to_r2
Simulación (dry-run) para ver qué se migraría:
python manage.py migrate_images_to_r2 --dry-run
Migrar solo un reporte específico:
python manage.py migrate_images_to_r2 --reporte-id=UUID_DEL_REPORTE
Limitar cantidad de imágenes (para pruebas):
python manage.py migrate_images_to_r2 --limit=10
Probar conexión con Cloudflare R2:
python manage.py cloudflare_r2 --action=test
